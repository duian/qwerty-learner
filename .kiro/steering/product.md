## Product Overview

Qwerty Learner is a typing practice and vocabulary learning application designed for keyboard workers who use English as their primary working language.

### Core Concept

Combines English vocabulary memorization with keyboard muscle memory training. Users type words to learn them, reinforcing both spelling and typing speed simultaneously.

### Key Features

- **Dictionary Practice**: Built-in word lists for CET-4/6, TOEFL, IELTS, GRE, GMAT, SAT, coding APIs, and more
- **Phonetic Display**: Shows pronunciation and phonetic symbols while learning
- **Dictation Mode**: Review mode after completing each chapter
- **Speed & Accuracy Tracking**: Real-time metrics for typing performance
- **Coder-Focused**: Special dictionaries for programming APIs (JavaScript, Python, Java, etc.)
- **Multi-Language Support**: English, Japanese, and other language vocabularies

### Target Users

- Developers and keyboard workers needing to improve English typing speed
- Students preparing for English exams (CET, TOEFL, IELTS, etc.)
- Anyone wanting to build muscle memory for English typing

### Design Philosophy

- Incorrect inputs require re-typing to prevent wrong muscle memory
- Quantified feedback (speed, accuracy) for measurable progress
- Practice with real words instead of pseudo-words for practical vocabulary building
